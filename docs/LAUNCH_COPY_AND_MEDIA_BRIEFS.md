**Maker comment:**

I built Humperdinck because I wanted voice tools that don't require sending every script and recording to an online generation service. Humperdinck brings voice creation, preset speech, sections and narration controls into a local-first desktop workflow.

It isn't magic: some models need a substantial first download, performance depends on your computer, and features differ by engine and platform. Voice cloning is intended only for voices you have clear permission to reproduce. The goal is a useful tool for creators who want more control over the process.

If you make tutorials, narration or voiceovers, I'd appreciate specific feedback: which workflow is currently most time-consuming for you, and which part of this local approach would be useful (or not)?
