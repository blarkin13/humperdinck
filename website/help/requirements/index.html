BEFORE YOU INSTALL

Will Humperdinck run on my computer?

Choose the installer for your CPU architecture and the model for your available memory. Large local voice models have different requirements from the application itself.

Installer compatibility

Important: Minimum supported OS builds, universal RAM/VRAM limits and guaranteed generation speeds are not yet certified across release hardware. The table describes current build targets, not guaranteed performance on every machine.

CPU, GPU and memory

  • Basic preset speech: smaller engines such as Kokoro and Piper are intended to work on compatible CPUs; speech speed still varies by processor.
  • Apple Silicon: MLX can accelerate supported Qwen models using unified memory. An 8 GB machine may run out of memory with larger models or other apps open; a working installation is not a guarantee of acceptable speed.
  • NVIDIA Windows/Linux: supported Qwen PyTorch engines may use CUDA when the NVIDIA driver and CUDA-enabled PyTorch environment are configured. GPU model and free VRAM matter; CUDA acceleration is not implied by merely owning an NVIDIA GPU.
  • CPU fallback: a large Qwen engine may fall back to CPU and run substantially more slowly. Try a smaller model if the first generation stalls or the computer becomes memory-constrained.
  • Minimum and recommended RAM/VRAM: not yet published as verified numeric thresholds. The model selection panel and the operating system's available memory should guide testing until a measured hardware matrix is released.

Storage, downloads and offline use

Installers and downloaded models are separate. The first model setup can require several gigabytes and additional temporary working space. Keep more free space available than the displayed download size, and check the filesystem containing the model cache—not only the system drive.

After downloading the selected model and engine, ordinary speech generation can work without internet. Initial model downloads, website/account sign-in, purchasing and update checks use network services. Keep an exported Pro license backup if you rely on offline activation.

Troubleshooting

Installer blocked by operating-system security

Verify the download source and checksum first. Unsigned Windows installers may be blocked by Smart App Control and unsigned/non-notarized macOS builds may be blocked by Gatekeeper. Do not turn off system-wide protection to install an unverified file; use a publisher-signed release when available.

Model download fails or reports corruption

Check the internet connection, free space on the model-cache volume, and any restrictive firewall. Reopen Models and retry or repair the model. The Kokoro download path verifies file checksums and rejects corrupt files.

Qwen says model is missing or generation fails

Open Models and check that the exact engine and model required by the selected voice are installed. A preview using one Qwen engine does not install every cloning or VoiceDesign checkpoint. Record the exact model name and error before contacting support.

Speech generation is slow, or the GPU is idle

Check the engine's reported processing device and actual CPU/GPU memory activity. Some engines are CPU-only; others require an MLX or CUDA-compatible installation. Benchmark a short, identical sample after warm-up and compare with a smaller preset voice.

No output or export seems missing

Confirm that a voice and engine are selected and the model is ready. Check the application's displayed save location (typically your Downloads folder) and that your device can play WAV or MP3. Preserve the exact error or failed-step text, not private project data.

Pro, sign-in or an offline license does not appear

Sign in using the account linked to the Pro purchase, verify your device connection, and use the application's existing license backup/restore workflow. An offline certificate and online account status are distinct. Do not email recovery codes, signed licenses or credentials to support.

Need more help?

See the installation walkthrough, then email support@humperdinck.studio with operating system/version, CPU/GPU, RAM, model/engine, app version, action attempted and exact error. You can omit personal scripts, recordings, account recovery codes and license keys.

Hardware requirements and troubleshooting will be updated as validated installer and model benchmarks become available. This guide does not promise every model on every supported operating system.
