SETUP & TROUBLESHOOTING

Install the studio.

A local-first desktop app for Windows, Mac and Linux. Installation and first-time model downloads are separate steps.

Available downloadsAll help topics

Before you download

Use only installers linked from humperdinck.studio. Check that the version, operating system and CPU architecture match your computer. If the release provides SHA-256 checksums, compare your file with the published value. An unsigned installer is not automatically malicious, but you should not disable your operating system's security protections just to install it.

Models are not all bundled with the app: the first setup may download several gigabytes, and larger models need more temporary free disk space than their final size.

Windows 10/11 · x64

  1. Get the Windows installer from the official download area, once a release is published.
  2. Follow the normal installer prompts. An unsigned build may be warned about or blocked by Windows Smart App Control. Humperdinck cannot guarantee installation where that policy is enforced; choose a publisher-signed build when available rather than disabling security features.
  3. Open Models, install a compatible engine, and select a voice. NVIDIA acceleration requires a working driver and a CUDA-capable PyTorch environment; otherwise Qwen uses the CPU.

macOS · Apple Silicon

  1. Choose the Apple Silicon DMG, not an Intel/x64 Linux or Windows installer.
  2. Open the disk image and install the application using its normal on-screen instructions. An unsigned, non-notarized app can be blocked by Gatekeeper. Use a future notarized release when required; do not bypass warnings from an unverified download.
  3. Choose an MLX-compatible model for Apple GPU processing. Larger models can exceed an 8 GB Mac's available unified memory.

Ubuntu/Debian Linux · x64

  1. Download the Debian .deb package for x64 once available.
  2. Use your normal package manager or graphical package installer. Review the package source and dependencies before granting installation privileges.
  3. Run Humperdinck and install a supported local engine. NVIDIA CUDA support depends on the installed driver and PyTorch package.

If a model download fails

Check your connection and available disk space in the model-cache volume. A partial or corrupted Kokoro model file is rejected and will be downloaded again; completed models are SHA-256 verified. For other engines, use the Models panel to repair or retry the installation. If Qwen is unexpectedly using the CPU, check the engine's reported device and driver configuration instead of assuming the app has selected the GPU.

Offline narration works after a supported engine and its model files are installed. Sign-in, software updates, and initial model downloads require network access.

Support

If installation fails, email support@humperdinck.studio with your operating system, CPU architecture, Humperdinck version, selected engine and the exact error text. Do not send account recovery codes, private signing keys, signed speaker authorization documents or unrelated personal recordings.

Paid Pro checkout is not currently enabled. Unsigned beta packaging and official published customer releases are different milestones.
